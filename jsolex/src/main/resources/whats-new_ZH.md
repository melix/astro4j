# 欢迎使用 JSol'Ex {{version}}！

## 5.4.3 版本新功能

- 模糊和锐化不再截断负值或高于白点的值。

## 5.4.2 版本新功能

- 图像查看器中显示的动画和视频现在可以裁剪、翻转或旋转。
- 如果 OpenGL 支持此前被禁用，现在可以在高级设置中重新启用。
- Python 脚本现在可以通过 `jsolex.emit` 输出动画。
- 仓库的脚本摘要现在会提示：有新版本脚本可用，但需要更新版本的 JSol'Ex。
- 修复部分电脑因显卡驱动故障而在启动时卡死或崩溃的问题。
- 修复批量模式下同时处理多个文件时，Python 脚本有时会输出其他文件图像的问题。
- 修复在文件之间导航时，图像审查器有时显示空白图像的问题。
- 修复主窗口脚本语言选择器在加载或保存脚本后一直处于锁定状态的问题。
- 记录处理参数的 `config.json` 文件现在会与日志文件一起保存在生成图像旁边，而不再保存到视频所在文件夹。
- 修复饱和圆面模式下由于圆面周围的光晕，导致太阳圆面检测结果过大的问题。

## 5.4.1 版本新功能

- 更精确地检测谱线弯曲，从而提高重建图像的几何精度。
- 更充分地利用处理器核心，加快图像生成。
- 修复部分像素偏移被误判为超出范围，导致脚本失败或使用错误图像的问题。
- 新增 ImageMath 函数 `descatter`，用于去除仪器内部散射光在太阳圆面周围留下的多余背景。
- 新增“在完整光谱中自动搜索”谱线检测方式并设为默认，可识别列表中没有的谱线。
- 选择谱线后，JSol'Ex 现在会核实检测到的是否确为该谱线；如果相邻谱线更暗，则会自动校正。
- 新增铁线（Fe I 5302），可作为日冕成像的参考。
- 在波长列表中选择“其他”后，现在可直接输入观测谱线的波长，无需先将其添加到谱线列表。
- 移除汞线（e）；它是光谱灯的谱线，而不是太阳谱线。
- 修复脚本强制指定的处理参数中只要有一个无效，其他参数也会全部被忽略的问题。
- 修复 `weighted_avg` 和 `weighted_avg2` 使用最后一张堆叠图像的太阳圆面位置，而不是所有图像的平均位置，导致裁剪和最终拉伸可能错位的问题。
- 修复 `noise_sigma` 在含有大面积截断或饱和区域的图像上失效，导致使用 `weighted_avg` 或 `weighted_avg2` 堆叠时单张图像权重过大的问题。
- 降低使用 `avg`、`min`、`max`、`weighted_avg` 和 `weighted_avg2` 合并大量图像时的内存需求，使内存较少的电脑也能处理大型堆叠。
- 修复批处理中只有一个文件时，`weighted_avg` 和 `weighted_avg2` 脚本函数失败的问题。
- 日珥高度标尺的标签现在可以旋转，避免遮挡日珥。
- Python 脚本现在可以像 ImageMath 脚本一样，直接在图像之间使用 `+`、`-`、`*` 和 `/`。
- 修复将数字写在前面的减法或除法（如 `1000 - image`）会反向计算的问题。
- 新增脚本函数 `img_percentile`，用于测量图像指定区域的参考电平，避免少量异常像素干扰结果。
- `img_min` 和 `img_max` 现在与其他测量函数一样支持遮罩，可将测量限制在图像的指定区域。
- 脚本错误现在会显示完整详情，不再出现空白消息而无法判断原因的情况。
- 几何校正现在以一次更高质量的处理完成，可保留更多细节，尤其是水平方向的细节。
- 现在以亚像素精度定位太阳日缘和谱线。

## 5.4.0 版本新功能

- **脚本的重要变更**：图像之间的运算不再为了保持结果可显示而自动调整数值范围。减法会保留负值，而不是移动整张图像使其为正；图像平均也会保留超出白色显示上限的数值。因此，进行连续谱相减的脚本显示效果可能与以前不同，可使用新的 `lift` 函数恢复旧版结果。

### 批处理模式

- 批处理现在支持往返扫描：文件按拍摄时间排序，并自动每隔一次扫描翻转一次图像。
- 批处理现在可以监视目录，并自动添加其中新出现的 SER 文件。
- 现在可以向已完成的批处理中继续添加文件，而无需重新处理已经完成的文件。
- 批处理现在可以只翻转指定时间之前或之后拍摄的文件，适用于观测期间方向发生变化的情况，例如中天翻转。
- 批处理中处理单个文件时出现的脚本错误，现在会显示在最终错误对话框中，而不再只写入单个文件的日志。

### 处理和图像

- 新增“最佳方法”对比度增强选项：根据检测到的谱线自动选择最佳技术，钙线使用 CLAHE，其他谱线使用自动拉伸。
- 堆叠工具生成的图像现在可以分享到 SpectroSolHub。
- 分享到 SpectroSolHub 时，现在可以选择用于校验方向的参考图像。
- 堆叠图像现在会保留源图像的谱线，不再回退到错误波长。
- 旋转图像时，新产生的角落区域现在使用图像背景电平填充，而不是黑色；显式提供填充值时除外。
- FITS 文件和 Python 脚本中记录的太阳视直径不再全年保持不变，现会随季节在一月增大、七月减小。

### ImageMath 脚本

- 新增脚本函数 `load_sdo`，下载与观测时间最接近的太阳动力学观测台图像，并自动定位太阳圆面，方便与自己的图像并排比较。
- `radius_rescale2` 现在支持参考图像，可将参数图像调整到相同的太阳圆面大小，无需手动计算数值。
- `draw_text` 现在支持负坐标，从右侧和底部边缘计算，因此无论图像大小如何，都能将文字放在下方角落。
- `unsharp_mask` 不再在锐化的同时提高整张图像的亮度；相同强度下，结果会比以前更暗、对比度更高。
- 新增脚本函数 `noise_sigma`，用于测量图像噪声，使脚本能够自动评价批处理中各文件的质量。
- `deghost` 现在可以同时去除太阳圆面周围多个位置的反射鬼影。
- 新增 `clamp` 函数，将图像限制在指定数值范围内（默认使用可显示范围）；新增 `lift` 函数，整体提高图像数值以消除负值。
- `signed_diff` 函数已弃用；普通的 `a - b` 减法现在具有完全相同的行为。
- 新增 `weighted_avg2` 函数，同时支持逐图像权重和异常值剔除，使质量更好的图像能在堆叠中贡献更多。
- `mtf_autostretch` 和 `percentile_stretch` 现在可以在遮罩区域内计算统计值，例如太阳圆面外的一圈区域，使结果不受裁剪系数影响。
- `mtf` 和 `mtf_autostretch` 现在使用完整的可显示范围：最暗处会达到黑色而不再停留在灰色，图像对比度更高，设置的背景电平也会准确呈现。
- `bg_model` 现在可以限制在遮罩区域内，使背景在远离太阳圆面的一圈区域测量，而不会跟随圆面周围的信号。
- `img_avg` 和 `img_median` 现在也可以限制在遮罩区域内。
- 新增 `log_stats` 函数，在不修改图像的情况下将图像统计值写入日志，便于观察数值在批处理文件之间的变化。
- `percentile_stretch` 现在支持含负值的图像（如连续谱相减图像），并可通过 `clip: 0` 保留完整动态范围。
- 新增 `destripe` 函数，可去除任何图像中的水平条纹，包括连续谱相减图像等背景接近零的图像。
- 新增 `column_bg_model` 函数，用于模拟仪器内部散射光在扫描太阳圆面的各列中造成的额外背景，以便将其去除。
- 新增 `save_raw` 函数，以精确数值和元数据保存图像，通过 `load` 重新加载时不会出现 FITS 或 PNG 的精度损失。
- 在 `[outputs]` 部分，名称以 `__` 开头的变量不再视为输出：它仍会计算并可供其他表达式使用，但不会显示或保存。
- 脚本现在可使用 `inputFilesCount` 和 `keptFilesCount` 变量，获取处理文件数及筛选后保留的文件数。
- `draw_text` 现在可以通过 `%VAR_name%` 显示任意脚本变量的值。
- 将数值列表乘以或除以单个数字时，现在会对列表中的每个元素执行运算。
- `crop_ar` 生成的图像现在以所显示的活动区命名。
- 观测信息和 `draw_text` 现在可通过 `%INPUT_FILES%` 和 `%KEPT_FILES%` 显示处理文件数。
- 脚本现在可以强制指定所需的处理参数，例如禁用条纹校正或扩大裁剪范围，而不受处理参数界面中所选设置影响。

- 修复批处理同时启动的文件数远超配置上限，在大型批处理中可能耗尽内存的问题。

## SpectroSolHub 集成

[SpectroSolHub](https://spectrosolhub.com) 是一项新推出的 JSol'Ex 配套服务，目前处于测试阶段。它由 JSol'Ex 作者开发，方便您与社区分享太阳光谱仪图像。

![SpectroSolHub](/docs/spectrosolhub.png)

现在可以直接从 JSol'Ex 将处理后的图像发布到 SpectroSolHub。处理 SER 文件后，点击状态栏中的“SpectroSolHub”按钮即可打开发布向导；向导会引导您完成身份验证、图像选择、会话元数据和上传。

您也可以直接从脚本仓库管理器浏览并添加 SpectroSolHub 上的脚本仓库。点击“浏览 SpectroSolHub”，即可发现可用仓库并一键添加。

**注意：**将图像上传到 SpectroSolHub，即表示您授予对上传内容进行科学研究使用的非独占、全球性、免版税许可。

## 多普勒自转校正

JSol'Ex 5.0 新增“多普勒（已校正自转）”图像类型。
它使用二维多项式拟合移除平滑的太阳自转梯度，使色球层速度结构更加清晰。

新增两个 ImageMath 函数以支持自定义多普勒校正流程：`SIGNED_DIFF(a, b)` 计算两张图像的差并保留符号（不归一化）；`POLY_FIT_2D(image, degree)` 在太阳圆面内拟合二维多项式曲面。

## 光谱浏览器改进

此版本显著改进了光谱浏览器：

- 波长网格标签现在会随缩放级别自动调整，并增加次刻度和浅色网格线，便于阅读。
- 新增相对于仪器色散的缩放预设：25%、50%、75%、100%、150%、200% 和 400%。

## 新增 ImageMath 函数

- `COLLAGE`：使用文本模式创建图像布局，例如 `collage(".X. / X.X", images)` 会创建金字塔布局。
- `SIGNED_DIFF(a, b)`：计算两张图像之差并保留符号。
- `POLY_FIT_2D(image, degree)`：在太阳圆面内拟合二维多项式曲面。
