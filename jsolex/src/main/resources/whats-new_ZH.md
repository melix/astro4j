## 更简单的上手体验

JSol'Ex 更容易上手了。首次启动时，配置向导可帮助您处理第一个文件，无需研究各种选项。它会从采集软件的设置文件中读取相机信息，并让您通过照片选择光谱日像仪。望远镜、赤道仪和观测者信息均为可选项。

![配置向导](/docs/setup-assistant-en.png)

主页现在会显示处理时将使用的设置，并可恢复为自动设置。处理之前，如果文件是用与您的设备不同的相机录制的，JSol'Ex 会提醒您。

首次处理完成后，界面导览会向您介绍屏幕的各个区域。之后可随时通过“帮助”菜单再次打开。

![界面导览](/docs/guided-tour-en.jpg)

## 图像查看器中的调整

图像查看器为图像留出了更多空间：按钮排成两行并使用彩色图标，调整选项在图像旁边的面板中打开。现在还可以对图像进行模糊和锐化，包括 USM 锐化。图像拉伸速度也更快，特别是 CLAHE、CLAHE2 和 AutoStretch。

![图像查看器](/docs/image-viewer-en.jpg)

## Ellerman 炸弹与耀斑

Ellerman 炸弹的检测更加可靠，参考了 Stephan Schmelzing 描述的方法。每个检测到的 Ellerman 炸弹或耀斑都附带一张图表，将其谱线轮廓与周围区域进行比较。

## Python 脚本

**Python 虚拟环境现在必须使用 GraalPy 25.6 创建。** 如果您正在使用虚拟环境，请用此版本重新创建。

- Python 脚本中图像与 NumPy 之间的转换速度更快。
- 独立脚本工具现在可以使用 GraalPy 虚拟环境。

## 错误修复与改进

- 处理过程中内存占用更低。
- 已移除“内存占用调整”设置，因为不再需要。
- 修复了为校正 P 角而旋转的图像角落显示为白色的问题。
- 修复了独立脚本工具在配有显卡的电脑上运行失败的问题。
- 修复了 Python 脚本在独立脚本工具原生版本中无法运行的问题。
- 修复了打开新文件或显示图像时可能导致处理中断的错误。
- 修复了在处理完成之前创建动画或面板时出现的错误。
